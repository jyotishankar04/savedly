Collections group memories into folders; tags cut across them however you like.

![Organizing screen](/help/docs/organize.png)

## Let it organize itself

With AI configured, an incoming memory can be auto-tagged and, if it fits a clear recurring theme, auto-filed into a matching collection.

![The Collections page, with memories filed automatically](/help/docs/organize-1.png)

## Create your own collection

From the Collections page, give it a name, an icon, and an optional description.

![The new collection dialog](/help/docs/organize-2.png)

## Tag anything, anytime

Add or edit tags on any memory to group things your own way — tags aren't tied to a single collection.

![A memory's detail page, with its tags](/help/docs/organize-3.png)
