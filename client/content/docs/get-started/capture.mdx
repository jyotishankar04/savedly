Links, notes, images, documents, and voice all go through the same capture bar.

<GuideActions actions={[{ label: "Save something now", href: "/app/capture" }]} />
![Saving memories screen](/help/docs/capture.png)

## Save a link

Paste a URL. The page is fetched, read, summarized, and tagged automatically once AI is configured.

![The Quick Capture page with a link pasted in](/help/docs/capture-1.png)

## Save a note

Type plain text — an idea, a quote, a reminder. Notes are yours as typed; nothing is rewritten, only lightly spelling-corrected if it's a caption alongside a link.

![The Quick Capture dialog with a note typed in](/help/docs/capture-2.png)

## Upload a file

Images get OCR text extraction plus a visual description; PDFs get their text extracted (large ones are summarized from page one). Voice memos save today — automatic transcription is on the way.

![The Quick Capture page with an image attached](/help/docs/capture-3.png)
