Save the page you're on without leaving it. The extension is built, but it isn't published to the Chrome Web Store yet, so there's nothing to install from the store for now.

## Current status

The Browser extension is marked **Coming soon** on the Integrations page. Until it's published, use [Quick Capture](/help/docs/get-started/capture) to save links and notes from inside the app.

![The Integrations page, with the browser extension marked Coming soon](/help/docs/extension-1.png)

## What it will do

Once it's available, the extension adds the current page to Savedly from the toolbar: click the toolbar icon to capture the tab, or use the right-click menu on a page, link or selection.

## The shortcut

The extension will also quick-save the current page in one keystroke with Ctrl+Shift+S (Cmd+Shift+S on Mac).
