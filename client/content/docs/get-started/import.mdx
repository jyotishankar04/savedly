## Export your bookmarks

From your browser's bookmark manager, export them as an HTML file — every major browser supports this.

![The Import page](/help/docs/import-1.png)

## Upload it

From the Import page, upload that file — or skip it and paste in a plain list of URLs instead.

![The Import page, with the upload area and the paste-a-list option](/help/docs/import-2.png)

## Let it process

Each link is saved and queued for the same enrichment as anything saved directly, one by one.

![The Import page showing the imported batch](/help/docs/import-3.png)
