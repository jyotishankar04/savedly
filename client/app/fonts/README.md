# Fonts

These files are bundled so that building the site needs no network access.
They are the Latin subsets served by Google Fonts, unmodified.

| File | Font | Licence |
| --- | --- | --- |
| `inter-latin.woff2` | Inter (variable, weights 100–900) | SIL Open Font License 1.1 |
| `geist-latin.woff2` | Geist (variable, weights 100–900) | SIL Open Font License 1.1 |
| `geist-mono-latin.woff2` | Geist Mono (variable, weights 100–900) | SIL Open Font License 1.1 |
| `fraunces-italic-400-latin.woff2` | Fraunces Italic 400 | SIL Open Font License 1.1 |

They are loaded with `next/font/local` in `app/layout.tsx` and
`components/marketing/landing/how-it-works-section.tsx`.
